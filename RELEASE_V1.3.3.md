# RJP Cleaner V1.3.3

## Nova via iOS gratuita

- Novo workflow `iOS Unsigned IPA (AltStore-SideStore)`.
- Gera um `.ipa` de dispositivo iOS sem assinatura Apple paga.
- Publica o IPA como Artifact do GitHub Actions.
- Inclui SHA-256 do IPA.
- Compatível com sideload através de SideStore e AltStore Classic, que tratam da assinatura com Apple Account gratuita.
- Mantém Android APK e iOS Build de validação já existentes.
- Adicionado `IOS_ALTSTORE_SIDESTORE.md` com instruções de instalação e atualização.
